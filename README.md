# 💡 Smart LED Driver Node

### IoT-Based Smart Lighting Control System

> **Final Year B.Tech Project | Academic Year 2025–2026**

An industry-collaborative final-year engineering project focused on developing an intelligent and cost-effective system for controlling LED lighting using IoT technology.

---

## 🤝 Industry Collaboration

This project was developed in collaboration with:

**PMEA Solar Tech Solutions LTD.**

The project focuses on applying embedded systems and IoT technology to existing LED lighting infrastructure.

---

## 🎯 Project Objective

The main objective of the **Smart LED Driver Node** is to develop an intelligent lighting control system that can upgrade conventional LED lighting with smart control and monitoring capabilities.

Key objectives include:

- Enable IoT-based control of LED lighting
- Provide wireless control using Wi-Fi
- Support independent control of multiple LED loads
- Develop a modular and maintainable system
- Reduce unnecessary replacement of existing lighting infrastructure
- Improve flexibility and scalability of smart lighting systems

---

## ✨ Key Features

- 🌐 IoT-based Smart Lighting Control
- 📶 Wi-Fi Connectivity
- ⚡ ESP32-based Controller
- 🔌 Multi-channel Relay Control
- 📱 Remote Control Capability
- 🎙️ Voice Assistant Integration
- ☁️ Cloud Connectivity
- 📡 MQTT Communication
- 🔧 Custom PCB Design
- 💡 Integration with Existing LED Driver Systems
- ♻️ Modular and Cost-Effective Design
